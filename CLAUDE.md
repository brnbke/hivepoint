## Overview

HivePoint is a single-page static website for a healthcare strategy advisory firm. There is no build system, no package manager, and no framework — the entire site is one file.

## Structure

- `index.html` — the entire site: HTML structure, all CSS (inline in `<style>`), and content
- Image assets (`.jpg`, `.png`) sit in the root directory alongside `index.html`
- `404.html` is auto-generated by CI from `index.html` — do not edit it directly

## Deployment

Pushing to `main` triggers `.github/workflows/static.yml`, which deploys to GitHub Pages. The workflow copies `index.html` → `404.html` before uploading, so all unknown paths fall back to the site.

## Development

Open `index.html` directly in a browser — no server required. For live reload during editing:

```sh
npx serve .
# or
python3 -m http.server 8080
```

## Key conventions

- All CSS lives in the `<style>` block in `<head>` — no external stylesheets
- Responsive breakpoint is `@media (max-width: 968px)`
- All page sections are wrapped in `<main>` for accessibility; the nav and footer sit outside it
- Page sections map directly to nav anchor IDs: `#about`, `#expertise`, `#how-we-work`, `#people`, `#contact`
- Max content width is `1400px`, enforced with `max-width` + `margin: 0 auto` on section wrappers
- The `hivebg.png` image is used as a CSS `background` on the hero — not an `<img>` tag
